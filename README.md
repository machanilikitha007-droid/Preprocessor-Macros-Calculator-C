# Preprocessor Macros Calculator in C

## Project Description

A simple C program that demonstrates the use of preprocessor macros in C. The program defines macros for basic arithmetic operations and uses them to calculate addition, subtraction, multiplication, and the square of a number.

## Features

- Demonstrates `#define` preprocessor directive
- Perform addition using a macro
- Perform subtraction using a macro
- Perform multiplication using a macro
- Calculate square using a macro
- Simple and easy-to-understand program

## Technologies Used

- C
- C Preprocessor
- `#define`
- Macros
- Standard Input/Output

## How to Run

1. Create a file named `preprocessor_calculator.c`.
2. Compile the program using a C compiler.
3. Run the compiled program.

Example using GCC:

```bash
gcc preprocessor_calculator.c -o preprocessor_calculator
